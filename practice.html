01

The method: V · R · N · C · D

Five steps solve almost every merger shareholding question. Say it out loud: Value, Ratio, New shares, Cancel, Divide.

V

Value per share

Value each company (SOTP, DCF, multiples), then divide by its own shares. ₹ cr × 10 ÷ mn shares

R

Ratio

target ₹/sh ÷ acquirer ₹/sh. Write as N : 10. Ignore face value.

N

New shares

target shares × ratio, but only for target shares held by outsiders.

C

Cancel

Remove acquirer shares the target owned; never issue shares to yourself.

D

Divide

Each holder's shares ÷ new total. Check: value per share unchanged = fair.

Demerger rule: the mirror

New co shares to a holder = parent shares × entitlement ratio. Percentages copy the parent's on the record date. If the parent keeps X%, holders get (1 − X) and total = holders' shares ÷ (1 − X).

Look-through rule

Your real share of a business = direct stake + Σ (your stake in a company × its stake in the business). Multiply along each chain, add the chains.

Six traps that cost marks

✗
Using face value to set the ratio. Only value per share matters.
✗
Forgetting to cancel the holdco's stake, which roughly doubles the dilution.
✗
Issuing shares for the acquirer's own stake in the target.
✗
Subtracting debt twice (inside the business and again at holdco level).
✗
Thinking a demerger ratio creates value. In a mirror demerger nothing changes economically.
✗
Ignoring order in composite schemes. Demerge-then-merge ≠ merge-then-demerge.
