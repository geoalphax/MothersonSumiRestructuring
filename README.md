# Restructuring Academy

A static study site on Indian mergers, demergers and schemes of arrangement, built around the 2020 Motherson Sumi restructuring.

- `index.html` home and learning path
- `motherson.html` the case, maths and assignment
- `schemes.html` schemes of arrangement 101
- `practice.html` practice lab with 24 cases
- `assets/` shared CSS and JS
- `Restructuring_Shareholding_Practice.xlsx` Excel practice workbook

Deploy: push this folder to a GitHub repo and enable Pages (main branch, root).
